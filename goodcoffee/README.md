# Good Coffee — сайт кофейни

Одностраничный сайт кофейни Good Coffee (ул. Плеханова, 22, Москва).
React 19 + TypeScript (TSX) + SCSS, сборка на Create React App.

## Запуск

```bash
npm install
npm start     # http://localhost:3000
npm run build # продакшн-сборка в build/
```

## Что где лежит

```
public/
  images/          фотографии кофейни (см. images/README.md)
  index.html       мета-теги, подключение шрифтов
src/
  components/      по папке на секцию: компонент + его стили
  data/            весь редактируемый контент — меню, контакты, отзывы
  hooks/           useReveal — появление блоков при скролле
  styles/          переменные, миксины и глобальные стили
```

## Как менять контент

Тексты и цифры вынесены в `src/data/`, править их можно не заглядывая
в разметку:

| Файл              | Что содержит                                     |
| ----------------- | ------------------------------------------------ |
| `info.ts`         | адрес, телефон, часы работы, соцсети              |
| `menu.ts`         | позиции меню и цены                               |
| `reviews.ts`      | записки гостей со стены отзывов                   |
| `features.ts`     | карточки «кофе с собой», «свежая выпечка» и т.д.  |
| `gallery.ts`      | фотографии в секции «Атмосфера»                   |

⚠️ Часы работы в `info.ts` — заглушка: на фотографиях их не было,
впишите реальные.

## Секции страницы

Первый экран → О нас → Меню → Атмосфера → Отзывы → Контакты → подвал.

Меню на странице — не картинка, а воссозданная наборная доска из зала:
каждая буква стоит на отдельной белой плашке (`Menu/BoardText.tsx`),
под строками — деревянные рейки.

## Дизайн

Палитра снята с фотографий: жёлтый `#FFD400` с логотипа и стены, графит
`#34383B` со стен зала, крафт и дерево реек. Логотип собран в SVG
(`components/Logo`) — стакан с жёлтой крышкой играет роль буквы «G».
Шрифты: Unbounded (заголовки), Manrope (текст), Oswald (доска меню).

Вёрстка адаптивная: 4 колонки на десктопе, 2 на планшете, 1 на телефоне;
на мобильных шапка сворачивается в бургер-меню. Анимации отключаются
при `prefers-reduced-motion`.
