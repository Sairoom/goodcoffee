# Фотографии для сайта

Положите сюда фотографии кофейни ровно с этими именами — сайт подхватит их
сам. Пока файла нет, на его месте показывается аккуратная тёмная заглушка
с подписью (сайт при этом не ломается).

| Имя файла              | Что на фото                                                        | Где используется          |
| ---------------------- | ------------------------------------------------------------------ | ------------------------- |
| `iced-coffee.jpg`      | Холодный кофе в руке на фоне вывески Good Coffee                     | Первый экран, галерея     |
| `drink-latte.jpg`      | Напиток со сливочной шапкой и семечками рядом с крафт-пакетом        | Первый экран, галерея     |
| `interior-machine.jpg` | Кофемашина La Carimali, картины и жёлтая стена                       | Секция «О нас», галерея   |
| `window-bar.jpg`       | Барная стойка у панорамного окна                                     | Галерея                   |
| `wall-poster.jpg`      | Станция с крышками, трубочками и постером со слоганом                | Галерея                   |
| `facade-window.jpg`    | Окно кофейни в кирпичном фасаде                                      | Галерея                   |
| `menu-board.jpg`       | Доска меню с наборными буквами                                       | Галерея                   |
| `reviews-wall.jpg`     | Пробковая доска со стикерами от гостей                               | Галерея                   |

Рекомендации: ширина 1600 px хватит с запасом, формат `.jpg` или `.webp`
(если меняете расширение — поправьте пути в `src/data/gallery.ts`).

Логотип для favicon можно заменить в `public/favicon.ico`.
